NonFunctional – Create Course

Bộ test kiểm tra khả năng tiếp cận của thông báo lỗi khi bỏ trống tên
đầy đủ hoặc tên ngắn của khóa học.

Cài Selenium và cấu hình .env theo README ở thư mục Feature002.
Chạy các lệnh sau từ thư mục Feature002.

    python .\run.py NonFunctional --dry-run
    python .\run.py NonFunctional

Bộ test dùng moodle_config.json của Level 2. Có thể dùng --base-url
để đổi địa chỉ Moodle hoặc --config để chọn file cấu hình khác.
