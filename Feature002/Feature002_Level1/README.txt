Level 1 – Create Course

Cài Selenium và cấu hình .env theo README ở thư mục Feature002.
Chạy các lệnh sau từ thư mục Feature002.

    python .\run.py Level1 --dry-run
    python .\run.py Level1
    python .\run.py Level1 --case TC-002-005

Có thể lặp --case để chọn nhiều ca. Nếu địa chỉ Moodle thay đổi,
thêm --base-url vào lệnh chạy. Dữ liệu test nằm trong create_course_cases.csv.
